# 0023. A dataset version is an episode selection or a folder of files

Status: Accepted (2026-11-26); supersedes in part 0001 (its "Dataset versions" section)
Covers: `packages/prov/src/prov/datasets/tables.py`, `packages/prov/src/prov/datasets/members.py`, `packages/prov/src/prov/artifacts/tables.py`
PR: https://github.com/v-sangli/prov/pull/12

## Context

ADR 0001 made every dataset version an episode selection: a `ds_` record with `uri: null` and a
members file, written by `prov dataset freeze`, never by a run. Some datasets are not selections
of episodes: clips generated by a run, or a corpus converted from elsewhere. They have bytes, and
they need lineage back to the run and code that made them. `prov publish --kind dataset` already
stored such a folder, but the record had no members file, so every catalog rebuild failed on it
(`FileNotFoundError`), and `prov.members` called it "not a dataset".

## Decision

- A dataset version (`ds_`, aliased `ds:<name>/<n>`) is one of two shapes:
  - an episode selection: `prov dataset freeze`, as in 0001 (`uri: null`, members file
    `registry/datasets/<ds_id>.txt`, no `produced_by`);
  - a files dataset: `prov publish <dir> --kind dataset --alias ds:<name>/<n>` or
    `prov.publish(path, "dataset", alias=...)`, with its bytes in `store/datasets/<ds_id>/`
    (read-only) and no members file. Inside `prov run` its `produced_by` is the run.
- The shape is read from the registry, not from a field: a dataset record with a members file is
  a selection. `dataset_members` is built from the members files that exist, so a files dataset
  contributes no rows.
- Lineage labels a files dataset `dataset, files` (a selection keeps `N episodes in M sessions`);
  its edge is the ordinary `produced` edge from its run (amends 0002's dataset node label).
- `prov.path(rec)` returns a files dataset's folder. `prov.members` and `prov.dataset_sessions`
  on it raise `DatasetError("<ref> holds files, not episodes; use prov.path")`.
- Not built: numbering on publish (the version is given in `--alias`) and `-train` / `-holdout`
  siblings for files datasets.
- Versions: prov 0.7.0.

## Consequences

- Easier: generated or converted data is versioned and traced like any artifact;
  `prov trace ds:<name>/<n>` reaches the producing run and its code snapshot.
- Easier: one alias kind, `ds`, for everything a training run loads as data.
- Harder: code reading a `ds_` must know which shape it holds; `members` says so when asked the
  wrong question.
- Unchanged: episode selections behave exactly as before, and `freeze` numbering counts any
  numeric version of the name, published ones included.
