# Spec: docs are lineage nodes

Branch: `feat/doc-nodes` · Mode: `feat/` extend · Versions: prov 0.5.0, prov-journal 0.2.0,
prov-skills 0.1.1

## Contract (agreed 2026-11-21)

- A doc is a Markdown file inside a git repo with an ID `doc_<ULID>`, kept in its frontmatter
  as `id:`. Registering it records the repo, its upstream remote (`origin`, or none), its
  path in the repo, its title, and a version.
- Everything counts as a citation: every prov ID and every alias anywhere in the file,
  frontmatter or body; aliases resolve to IDs; the doc's own ID is not a citation. A cited ID
  that is not in the registry fails the registration loudly.
- A version is (last commit that touched the file or None, dirty flag, registered time, cites);
  one is appended only when (commit, dirty, cites) differs from the last.
- A loose file (in no git repo) is refused: "fold it into a journal first". Folding is an agent
  rule in the journal skill, not code.
- Lineage: a cited thing → the doc (`cites`). `prov trace doc_…` shows what the doc rests on;
  `prov uses <id>` lists the docs citing it. `prov show doc_…` prints the record.
- `prov-journal new` writes `id:`; `prov-journal register` registers every dated journal doc
  (`journal/YYYY/MM/*/README.md`). Registration is explicit.

## Interface sketch

```python
# packages/prov/src/prov/core/ids.py      PREFIXES += {"doc": "doc"}
# packages/prov/src/prov/core/layout.py   DOCS_DIR = "records/docs"; doc_record(doc_id) -> str
# packages/prov/src/prov/core/errors.py   class DocError(ProvError)
# packages/prov/src/prov/docs/            (layer 3)
class DocVersion(Record):
    commit: str | None
    dirty: bool
    registered: datetime
    cites: list[str]

class DocRecord(Record):
    id: str
    repo: str            # repo directory name
    remote: str | None   # origin URL
    path: str            # relative to the repo root
    title: str           # first "# " heading, else the file name
    created: datetime
    versions: list[DocVersion]

def register(ctx, path: Path) -> DocRecord   # reads and resolves cites before the lock;
                                             # writes and commits under RegistryLock
def load(ctx, doc_id: str) -> DocRecord
```

Catalog (internal, the lineage-generalization choice): each `CatalogTables` bundle contributes
`nodes` SQL (`id, label`) and `edges` SQL (`src, rel, dst`); the catalog builds two views,
`nodes` and `edges`, as their unions. `prov.lineage` walks `edges` and labels with `nodes`,
with no per-kind code. Docs add tables `docs (id, repo, remote, path, title, created)` and
`doc_cites (doc, target)` (latest version) and contribute their nodes and `cites` edges.

Oracle: every existing lineage test (`trace` / `uses` output text included) passes unedited.

## Variation axes

Unchanged: recording formats, catalog tables (now also contributing nodes and edges), CLI
groups; journal lint rules; skills.
